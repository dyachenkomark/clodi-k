# cloDICK — роадмап и стек

> Черновик v0.3 (2026-09-26). Живой документ: правим по мере уточнения этапов.

## 1. Что строим

Лёгкий десктоп-компаньон для Windows: персонаж живёт поверх экрана и каждый день
напоминает про ключевые дела. Цель — минимум 15 минут в день на каждое направление.

- **Направления (модули):** спорт, учёба, язык. Список расширяемый.
- **Персонаж cloDICK:** пиксельный енот со своим домиком. Сидит у домика, иногда гуляет по краю экрана. По клику открывает чек-лист дня.
- **Телефон:** Telegram-бот — отметить выполнение, получить статус и напоминание.
- **Система:** показывает загрузку оперативной памяти в процентах.
- **Тренировки:** результаты скидываю в Telegram обычным текстом, они сохраняются в базу.
- **Анализ:** LLM через API разбирает записи и даёт сводки и советы.
- **Статистика:** смотрю в Excel.
- **Потом:** мотивация — серии дней, очки, настроение персонажа.
- **Ограничение:** не прожорливый. Цели ниже.

### Принятые решения

| Вопрос | Решение |
|---|---|
| Бот при выключенном ПК | Молчит, это нормально. Бот живёт на компьютере. |
| Как засчитывать день | Галочка «сделал». Без таймеров и автоопределения. |
| Персонаж | Пиксельный енот с домиком. Иногда гуляет. |
| Графика | Спрайты-заглушки рисуем сами в пиксель-арте, потом можно заменить. |
| Оперативная память | Только процент загрузки. Без порогов и списка процессов. |
| Язык | Английский и испанский на сайте в браузере. Одна общая галочка «Язык». Ссылку на сайт добавим позже. |
| База данных | SQLite на компьютере. В ней отметки, тренировки и результаты анализа. |
| Анализ | Claude API, модель `claude-opus-5`. |
| Статистика | Excel читает CSV-выгрузку через Power Query. |
| Граница дня | День начинается в 04:00, чтобы ночные занятия шли в зачёт вчерашнего дня. Настраивается. |

### Бюджет ресурсов

| Метрика | Цель |
|---|---|
| RAM в простое | до 80 МБ |
| CPU в простое | меньше 1% |
| Запуск | до 3 сек |
| Размер установщика | до 60 МБ |

## 2. Стек

| Задача | Выбор | Почему |
|---|---|---|
| Язык | Python 3.12 (совместимо с 3.11) | Решено. Быстро писать, богатая экосистема. |
| Окно персонажа и трей | PySide6 (Qt) | Прозрачное окно без рамки поверх всех окон, нормальная альфа-прозрачность, трей, таймеры. Tkinter легче, но даёт рваные края у спрайта. |
| Анимация | Спрайт-листы PNG, 8–12 кадров/сек, пауза при бездействии | Дёшево по CPU. Никакого браузерного движка. |
| Хранилище | SQLite (встроенный `sqlite3`) | Один файл, ноль зависимостей, легко бэкапить. |
| Настройки | TOML-файл | Читается руками, `tomllib` встроен. |
| Метрики системы | `psutil` | RAM, топ процессов, кроссплатформенно. |
| Telegram-бот | `aiogram` 3, long polling | Не нужен белый IP или сервер. Бот живёт в том же процессе, в отдельном потоке. |
| Расписание | Qt-таймеры + своя простая логика | APScheduler избыточен для нескольких напоминаний в день. |
| Учёба | `git` через `subprocess` | Коммиты за день, изменённые файлы. GitPython не нужен. |
| Анализ через LLM | `anthropic` SDK, модель `claude-opus-5`, структурированный вывод | Разбор текста тренировок в таблицу и недельные сводки. Ключ API хранится в `keyring`. |
| Excel | CSV-файлы + готовая книга с Power Query | Excel не читает SQLite без ODBC-драйвера. CSV обновляются приложением, книга подтягивает их при открытии. |
| Сборка в exe | PyInstaller (режим onedir) | Надёжно и быстро стартует. Nuitka рассмотрим позже, если захотим меньше и быстрее. |
| Установщик | Inno Setup | Нормальный setup.exe, ярлыки, автозапуск, деинсталляция. |
| Зависимости и окружение | `uv` | Быстро, lock-файл. |
| Качество | `ruff`, `pytest`, GitHub Actions на Windows-раннере | Сборка exe в CI на каждый релиз. |

### Архитектура

```
clodick/
  core/        домен: задачи дня, прогресс, серии; не знает про UI и Telegram
  storage/     SQLite-репозитории, миграции
  modules/     плагины направлений: sport, study, language (общий интерфейс)
  system/      мониторинг RAM
  desktop/     Qt: персонаж, чек-лист, трей
  bot/         Telegram-бот
  app.py       точка входа, связывает всё через шину событий
```

Ядро и модули не зависят от интерфейсов. Десктоп и бот — два «пульта» к одному ядру.
Так проще тестировать и потом добавить macOS или веб.

Каждый модуль реализует один интерфейс: название, цель на день, прогресс за сегодня,
список действий, способ отметить выполнение. Новое направление = новый модуль.

## 3. Данные

### Почему SQLite, а не серверная база

Пользователь один, данные живут на одном компьютере, бот работает там же.
SQLite — это полноценная SQL-база в одном файле: транзакции, индексы, миграции.
Сервер вроде PostgreSQL понадобится, только если бот переедет на VPS или появится синхронизация между устройствами.
Код хранилища изолирован, так что переезд затронет только слой `storage/`.

### Что храним

| Таблица | Что в ней |
|---|---|
| `completions` | Галочки: направление, день, время, откуда отмечено. Уже есть. |
| `workouts` | Тренировка: день, время, исходный текст из Telegram как есть. |
| `workout_sets` | Разобранные подходы: упражнение, подходы, повторы, вес, время, дистанция. |
| `analyses` | Ответы LLM: период, тип сводки, текст, модель, стоимость. |

Исходный текст тренировки храним всегда. Если разбор ошибся или улучшим промпт, пересоберём таблицу подходов из исходников.

### Поток тренировки

```
Telegram: «присед 3х10 60, подтягивания 4х8, бег 5 км 28 мин»
  → сохраняем текст в workouts
  → LLM разбирает в строгую JSON-схему → workout_sets
  → бот отвечает таблицей: «Записал 3 упражнения, проверь»
  → галочка «Спорт» ставится автоматически
```

Если API недоступен, текст всё равно сохраняется. Разбор повторится позже.

### Анализ через LLM

- **Разбор тренировок** — после каждой записи.
- **Недельная сводка** — по воскресеньям в Telegram: что сделано, прогресс в весах и объёме, пропуски, совет на неделю.
- **Вопрос по запросу** — команда в боте, например «как у меня с подтягиваниями за месяц».
- В LLM уходят только агрегаты и записи за нужный период, не вся база.

Примерная стоимость на `claude-opus-5` ($5 за миллион входных токенов, $25 за миллион выходных):

| Операция | Токены на вход / выход | Цена за раз |
|---|---|---|
| Разбор одной тренировки | ~1 000 / ~300 | ~$0.01 |
| Недельная сводка | ~20 000 / ~2 000 | ~$0.15 |
| Итого в месяц при 4 тренировках в неделю | | ~$1–2 |

### Excel

- Приложение пишет CSV-файлы в папку `export`: отметки по дням, тренировки, подходы.
- В комплекте готовая книга `cloDICK.xlsx` с Power Query, сводными таблицами и графиками.
- Книга обновляет данные при открытии или по кнопке «Обновить всё».
- Почему не писать сразу в xlsx: открытый в Excel файл заблокирован, и приложение не сможет его обновить. CSV такой проблемы не создаёт.

## 4. Этапы

### Этап 0. Фундамент — готово
- Скелет проекта, `uv`, `ruff`, `pytest`, CI.
- Схема SQLite: направления, записи активности, настройки.
- Конфиг, логирование в файл с ротацией.
- **Готово, когда:** `uv run clodick` запускается, тесты зелёные в CI.

### Этап 1. MVP на рабочем столе
- Енот с домиком над панелью задач. Домик перетаскивается мышью и запоминает позицию.
- Анимации: сидит, спит, машет, гуляет. Иногда уходит погулять вдоль края экрана и возвращается.
- По клику — чек-лист дня: спорт, учёба, язык. Галочка «сделал», у языка кнопка «открыть сайт».
- Напоминания по расписанию: енот выходит из домика и показывает пузырь с текстом.
- Процент загрузки RAM рядом с домиком.
- Иконка в трее: показать или скрыть, пауза, выход.
- **Готово, когда:** пользуюсь неделю каждый день, приложение укладывается в бюджет ресурсов.

### Этап 2. Telegram-бот
- Доступ только с моего chat ID.
- Команды: статус дня, отметить задачу, снять отметку, текущая RAM в процентах.
- Напоминания дублируются в Telegram.
- Токен хранится в Windows Credential Manager через `keyring`, не в коде.
- **Готово, когда:** с iPhone могу закрыть день без компьютера под рукой.

### Этап 3. Установка
- PyInstaller + Inno Setup, один setup.exe.
- Автозапуск с Windows, опционально.
- Сборка установщика в GitHub Actions по тегу.
- **Готово, когда:** ставлю на чистую Windows и всё работает.

### Этап 4. Модули вглубь
- **Учёба:** подключить локальный репозиторий, считать коммиты и время за день, показывать прогресс по курсу.
- **Язык:** английский и испанский. Галочка на каждый язык или одна общая, ссылки на сайт.
- **Спорт:** запись тренировок текстом в Telegram, разбор через LLM, журнал подходов, прогресс по неделям.
- Детали каждого модуля расписываем отдельно.

### Этап 5. Аналитика
- Выгрузка CSV и книга Excel с Power Query.
- Недельная сводка от LLM в Telegram.
- Вопросы к своей статистике через бота.
- **Готово, когда:** открываю Excel и вижу актуальные графики, в воскресенье приходит сводка.

### Этап 6. Мотивация
- Серии дней, очки опыта, уровни.
- Настроение и внешний вид персонажа зависят от прогресса.
- Недельная сводка в Telegram.

### Этап 7. Потом
- Статистика и графики.
- macOS и Linux.
- Сервер или облачная синхронизация, если понадобится работа при выключенном ПК.

## 5. Риски

- **Бот живёт на ПК.** Когда компьютер выключен, бот молчит. Принято. Если понадобится, вынесем бота на дешёвый VPS.
- **Антивирусы и PyInstaller.** Неподписанные exe иногда ловят ложные срабатывания. Помогает режим onedir и, при необходимости, подпись кода.
- **Qt весит.** Сборка будет около 40–60 МБ. Держим в рамках, исключая неиспользуемые модули Qt.
- **Ошибки разбора LLM.** Модель может неправильно понять запись. Бот всегда показывает, что записал, и даёт поправить.
- **Ключ API.** Хранится в Windows Credential Manager, в базу и логи не попадает.
- **Графика персонажа.** Начинаем со своих пиксельных заглушек. Хорошие спрайты енота и домика можно заказать или нарисовать позже, код от этого не меняется.
