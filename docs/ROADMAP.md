# cloDICK — роадмап и стек

> Черновик v0.9 (2026-09-26). Живой документ: правим по мере уточнения этапов.

## 1. Что строим

Лёгкий десктоп-компаньон для Windows: персонаж живёт поверх экрана и каждый день
напоминает про ключевые дела. Цель — минимум 15 минут в день на каждое направление.

- **Направления:** спорт, учёба, язык. Список расширяемый.
- **Персонаж:** у каждого свой, первый — пиксельный енот со своим домиком. Сидит у домика, иногда гуляет по краю экрана. По клику открывает чек-лист дня.
- **Телефон:** Telegram-бот — отметить выполнение, получить статус и напоминание.
- **Система:** показывает загрузку оперативной памяти в процентах.
- **Статистика:** по дням в Google Таблицу — что из задач сделано.
- **Друзья:** видеть, кто из друзей как закрывает свой день. Черновик — в разделе 4.
- **Потом:** запись тренировок текстом, анализ через LLM, мотивация.
- **Ограничение:** не прожорливый. Цели ниже.

### Принятые решения

| Вопрос | Решение |
|---|---|
| Бот при выключенном ПК | Молчит, это нормально. Бот живёт на компьютере. |
| Как засчитывать день | Галочка «сделал». Без таймеров и автоопределения. |
| Персонаж | Пиксельный енот с домиком. Иногда гуляет. |
| Графика | Спрайты-заглушки рисуем сами в пиксель-арте, потом можно заменить. |
| Оформление | Четыре темы: классика и три в стиле Claude. По умолчанию «Терракота». |
| Персонажи | У каждого свой. Персонаж — пакет с кадрами, енот — первый. Остальных создадим позже. |
| Аудитория | Люди «немного в IT». Упор на личную автоматизацию. |
| Оперативная память | Только процент загрузки. Без порогов и списка процессов. |
| Язык | Английский и испанский на сайте в браузере. Одна общая галочка «Язык». Ссылку на сайт добавим позже. |
| Граница дня | День начинается в 04:00, чтобы ночные занятия шли в зачёт вчерашнего дня. Настраивается. |
| База данных | SQLite на компьютере. |
| Статистика | Google Таблица: строка на день, колонка на направление. |
| Тренировки в MVP | Только галочка. Запись результатов текстом — позже. |
| Анализ через LLM | Отложен. Свой сервер vLLM с OpenAI-совместимым API. |

## 2. Стек

| Задача | Выбор | Почему |
|---|---|---|
| Язык | Python 3.12 (совместимо с 3.11) | Решено. Быстро писать, богатая экосистема. |
| Окно персонажа и трей | PySide6 (Qt) | Прозрачное окно без рамки поверх всех окон, нормальная альфа-прозрачность, трей, таймеры. Tkinter легче, но даёт рваные края у спрайта. |
| Анимация | Спрайт-листы PNG, 8–12 кадров/сек, пауза при бездействии | Дёшево по CPU. Никакого браузерного движка. |
| Хранилище | SQLite (встроенный `sqlite3`) | Один файл, ноль зависимостей, легко бэкапить. |
| Настройки | TOML-файл | Читается руками, `tomllib` встроен. |
| Метрики системы | `psutil` | Процент RAM, кроссплатформенно. |
| Telegram-бот | `aiogram` 3, long polling | Не нужен белый IP или сервер. Бот живёт в том же процессе, в отдельном потоке. |
| Google Таблица | `gspread` + сервисный аккаунт Google | Простой API для таблиц. Сервисный аккаунт не требует входа через браузер. Загружается, только если синхронизация включена. |
| Секреты | `keyring` (Windows Credential Manager) | Токен бота и ключи не лежат в файлах настроек и логах. |
| Расписание | Qt-таймеры + своя простая логика | APScheduler избыточен для нескольких напоминаний в день. |
| Сборка в exe | PyInstaller (режим onedir) | Надёжно и быстро стартует. Nuitka рассмотрим позже, если захотим меньше и быстрее. |
| Установщик | Inno Setup | Нормальный setup.exe, ярлыки, автозапуск, деинсталляция. |
| Зависимости и окружение | `uv` | Быстро, lock-файл. |
| Качество | `ruff`, `pytest`, GitHub Actions на Windows и Linux | Сборка exe в CI на каждый релиз. |

### Архитектура

```
clodick/
  core/        домен: задачи дня, прогресс, серии; не знает про UI и Telegram
  storage/     SQLite, миграции
  sync/        выгрузка в Google Таблицу
  system/      мониторинг RAM
  desktop/     Qt: енот, домик, чек-лист, трей
  bot/         Telegram-бот
  app.py       точка входа, связывает всё вместе
```

Ядро не зависит от интерфейсов. Десктоп и бот — два «пульта» к одному ядру,
а Google Таблица — ещё один получатель тех же данных.
Так проще тестировать и потом добавить macOS или веб.

## 3. Данные

### Почему SQLite, а не серверная база

Пользователь один, данные живут на одном компьютере, бот работает там же.
SQLite — это полноценная SQL-база в одном файле: транзакции, индексы, миграции.
Сервер вроде PostgreSQL понадобится, только если бот переедет на VPS или появится синхронизация между устройствами.
Код хранилища изолирован, так что переезд затронет только слой `storage/`.

База — главный источник правды. Google Таблица — её копия для просмотра.

### Что храним

| Таблица | Что в ней | Когда |
|---|---|---|
| `completions` | Галочки: направление, день, время, откуда отмечено. | Уже есть |
| `workouts` | Тренировка: день, время, исходный текст из Telegram. | Позже |
| `workout_sets` | Разобранные подходы: упражнение, повторы, вес, время. | Позже |
| `analyses` | Ответы LLM: период, тип сводки, текст. | Позже |

### Google Таблица

Строка на день, колонка на направление, в ячейках галочки:

| Дата | Спорт | Учёба | Язык | Сделано |
|---|---|---|---|---|
| 26.09.2026 | ☑ | ☐ | ☑ | 2/3 |
| 27.09.2026 | ☑ | ☑ | ☑ | 3/3 |

- **Направление синхронизации:** только из приложения в таблицу. Правки руками в этих колонках перезапишутся. Графики и свои формулы можно делать на соседних листах.
- **Когда пишем:** сразу после отметки или снятия галочки. Строка дня обновляется целиком, повторная запись безопасна.
- **Без интернета:** отметка сохраняется в базу, как обычно. При старте и раз в 15 минут приложение досинхронизирует последние 14 дней.
- **Новое направление:** в таблице появляется новая колонка.
- **Доступ:** сервисный аккаунт Google. Вы создаёте его в Google Cloud, скачиваете JSON-ключ и открываете таблице доступ на его почту. Пошаговую инструкцию напишем на этом этапе.

### Позже: тренировки и LLM

Когда галочек станет мало, добавим запись результатов:

```
Telegram: «присед 3х10 60, подтягивания 4х8, бег 5 км 28 мин»
  → сохраняем текст в workouts
  → LLM разбирает в строгую JSON-схему → workout_sets
  → бот показывает, что записал, и даёт поправить
  → галочка «Спорт» ставится автоматически
```

Исходный текст храним всегда, чтобы пересобрать подходы при ошибке разбора.
LLM — свой сервер vLLM. У него OpenAI-совместимый API, так что клиент — пакет `openai`
с адресом сервера в настройках и ключом в `keyring`. Слой анализа отдельный,
остальной код от выбора сервера не зависит.

## 4. Друзья и веселье

Регистрация через Telegram — решено. Где держать общую часть — предложение ниже.

### Идея

Друзья видят друг у друга, сколько задач закрыто сегодня и какая серия дней.
Не детали, а только «Маша: 3/3, серия 12 дней».

### Регистрация: аккаунт — это Telegram

Логинов, паролей и почты нет. У каждого уже есть Telegram, и бот знает, кто ему пишет.

```
1. Установил cloDICK → енот показывает код: «Напиши боту @clodick_bot: 4821»
   (или QR-код со ссылкой t.me/clodick_bot?start=4821)
2. Нажал Start в боте → бот связал твой Telegram с этим компьютером
3. Готово. Приложение получило свой токен и дальше синхронизируется само
```

Можно пользоваться и без компьютера: только ботом с телефона.
Это снижает порог для друзей, у которых нет Windows.

### Как объединяться в компанию

Самый простой способ — Telegram-группа:

- Создаёшь группу с друзьями и добавляешь туда бота.
- Все участники группы, кто нажал Start у бота, автоматически становятся «компанией».
- Бот пишет в группу короткие события: «Маша закрыла день 3/3». Вечером — сводка дня.
- Альтернатива без группы: команда `/invite` даёт ссылку-приглашение.

### Что видно на рабочем столе

- В чек-листе раздел «Друзья»: имя и прогресс, например «Маша 3/3 · Петя 1/3».
- Когда друг закрывает день, к твоему домику ненадолго приходит в гости его енот.
- Приватность: друзья видят только счёт и названия направлений. Каждое направление можно скрыть.

### Что это меняет в архитектуре

Нужен общий сервер. Бот больше не живёт на каждом ПК, а работает один на всех.

```
 ПК друга ─┐                         ┌─ Telegram (личка и группы)
 Мой ПК ───┼── HTTPS ── сервер ── бот┤
 iPhone ───┘   (API + база)          └─ телефоны без приложения
```

| Было в плане | Становится |
|---|---|
| Бот на моём ПК, свой токен от BotFather | Один бот на сервере, у друзей ничего настраивать не надо |
| Бот молчит, когда ПК выключен | Бот работает всегда |
| Отметки только в локальной базе | Локальная база остаётся главной для ПК, отметки синхронизируются с сервером |

- **Сервер:** бот, API и база. Где держать — таблица выше, рекомендация — Cloudflare.
- **Без интернета:** ПК копит отметки и отправляет, когда связь появится. При конфликте побеждает последняя отметка.
- **Что уходит на сервер:** только отметки по дням и имя из Telegram. Логи, память, файлы — нет.

### Без доступа к чужим компьютерам

Главный принцип: у общей части нет никакого пути внутрь чьего-то ПК.

- **Приложение только само ходит наружу** по HTTPS. Оно не открывает портов, к нему нельзя подключиться.
- **Сервер не умеет командовать.** ПК отправляет свои отметки, а получает только счёт, имена и персонажей друзей. Никаких команд, скриптов и файлов.
- **Токен устройства узкий.** Он даёт право ставить и снимать только свои отметки. Отзывается в боте одной кнопкой.
- **От друзей приходят только данные.** Персонаж друга — картинки и TOML без кода, с проверкой формата и лимитом размера. Плагины через сервер не раздаются никогда.
- **Автоматизация считается на своём ПК.** Наружу уходит только «сделано».
- **Не используем** VPN вроде Tailscale, общие папки, удалённый рабочий стол и прочее, что соединяет компьютеры напрямую.

### Где держать общую часть

| Вариант | Цена | Обслуживание | Минусы |
|---|---|---|---|
| **Cloudflare Workers + D1 + Pages** | Бесплатно | Сервера нет, HTTPS и адрес из коробки | Python на Workers только стал полноценным. Если библиотеки не заведутся, бота пишем на TypeScript |
| Supabase | Бесплатно | Сервера нет | Бесплатный проект засыпает после 7 дней без активности. Вход через Telegram делать самим |
| PocketBase на VPS | Около $4–5 в месяц | Обновления и бэкапы на нас | Свой сервер, хоть и простой: один файл, около 20 МБ памяти |
| Машина с vLLM | 0 | На нас | Домашнюю машину придётся открыть в интернет. Это риск, не советую |
| Google Таблица | 0 | — | Нет уведомлений и регистрации. Не советую |

**Рекомендация — Cloudflare.** Бесплатный план: 100 000 запросов в день, база D1 — 5 млн чтений и 100 000 записей в день.
Для компании из 10 человек, где каждый ПК синхронизируется раз в пару минут, это примерно 7 000 запросов в день — запас в десятки раз.

```
Telegram ──webhook──▶ Worker «бот» ──┐
Mini App (Pages) ──▶ Worker «API» ───┼──▶ D1 (SQLite): люди, компании, отметки
ПК друзей ──HTTPS──▶ Worker «API» ───┘
```

- Бот работает через webhook: Telegram сам присылает сообщения в Worker. Постоянно запущенный процесс не нужен.
- Mini App — статическая страница на Pages. Вход проверяется по подписи Telegram в initData.
- ПК привязывается кодом из бота и дальше знает только адрес API и свой токен.
- Если Cloudflare перестанет устраивать, та же схема переезжает на PocketBase или FastAPI на VPS: база остаётся SQLite.

### Как каждый ставит себе cloDICK

| Устройство | Как получить | Что ставить |
|---|---|---|
| Windows | Бот даёт ссылку на setup.exe | Установщик, дальше обновляется сам |
| iPhone, Android | Кнопка «Открыть енота» в боте | Ничего: Telegram Mini App |
| Mac, Linux | Та же кнопка в Telegram Desktop | Ничего. Нативная версия — потом |

**Путь нового друга:**

```
Ссылка-приглашение от тебя → бот: «Привет! Ты в компании Марка»
  ├─ кнопка «Открыть енота»   → Mini App прямо в Telegram, на любом телефоне
  └─ кнопка «Скачать для Windows» → setup.exe → код привязки → готово
```

**Windows.** Установщик собирается в GitHub Actions по тегу и публикуется в GitHub Releases.
Репозиторий публичный, так что скачивание бесплатное. Приложение раз в день проверяет новую
версию и предлагает обновиться. Без платной подписи кода Windows при первом запуске покажет
предупреждение SmartScreen. Для круга друзей хватит подсказки «Подробнее → Выполнить в любом
случае». Подпись купим, если пользователей станет много.

**Телефоны — Telegram Mini App.** Это веб-страница, которая открывается внутри Telegram
как приложение. Там тот же пиксельный енот, чек-лист и друзья. Плюсы:

- Не нужен App Store и аккаунт разработчика Apple за $99 в год.
- Вход автоматический: Telegram передаёт подписанные данные пользователя.
- Одна версия для iPhone, Android и компьютеров.
- Обновляется мгновенно, когда обновляем сервер.

Нативное приложение для iPhone не делаем: дорого, долго, а Mini App закрывает задачу.

### Свой персонаж у каждого

- Персонаж — пакет: `character.toml` с кадрами текстом или PNG-листами. Формат — в [CHARACTERS.md](CHARACTERS.md).
- Уже работает: енот вынесен в пакет, свои пакеты подхватываются из папки данных, персонажа можно сменить в меню на лету.
- Друзья видят твоего персонажа: в гостях у своего домика и в Mini App. Сервер хранит, кто какого персонажа выбрал, и раздаёт самодельные пакеты друзьям с проверкой формата и лимитом размера.
- Как создавать новых — решим позже. Варианты: рисовать в Aseprite или Piskel и загружать PNG, простой пиксельный редактор в Mini App, готовые персонажи от нас.

### Альтернатива без своего сервера

Общая Google Таблица: каждый пишет туда свою строку. Дёшево, но нет уведомлений,
нет удобной регистрации и каждому другу нужен ключ сервисного аккаунта. Не рекомендую.

## 5. Личная автоматизация

Для людей «немного в IT»: поставить программу, поправить конфиг, написать скрипт на пару строк.
Главная идея — задачи засчитываются сами, а cloDICK становится хабом личных автоматизаций.
Три уровня, от простого к сложному.

### Уровень 1. Правила без кода

Выбираются в настройках. Всё считается на своём ПК, наружу уходит только «сделано».

| Правило | Пример |
|---|---|
| Коммит в репозитории | Учёба засчитана, если сегодня был коммит в `D:\study` |
| Программа или сайт открыты N минут | Язык засчитан, если окно с «Duolingo» или Anki было активно 15 минут |
| Файл изменился | Спорт засчитан, если обновился файл с тренировками |
| Время в редакторе кода | Учёба засчитана после 30 минут в VS Code |

### Уровень 2. Полу-IT

- **Свои направления и правила** в `config.toml`, не только спорт, учёба и язык.
- **Личный токен и HTTP API.** Запрос `POST /api/done/sport` отмечает задачу. Звать можно откуда угодно: из «Команд» на iPhone, например при приходе в спортзал; из Home Assistant, IFTTT, cron.
- **Вебхуки наружу.** «День закрыт» или «серия 30 дней» вызывает твой URL: Notion, Home Assistant, Google Apps Script.
- **Консоль.** `clodick done sport` уже работает, её можно звать из Планировщика заданий и своих скриптов.
- **Готовые интеграции.** GitHub — коммиты, в том числе без ПК. WakaTime — время в коде. AnkiConnect — сколько карточек повторено. Strava — тренировки.

### Уровень 3. Для программистов

- **Python-плагины** в папке `plugins`: свои проверки вида «задача сделана?» и реакции на события вроде «день закрыт».
- **Свои персонажи и реплики.**
- **Потом:** каталог плагинов и персонажей от сообщества.

### Безопасность

- Плагин — это код на твоём компьютере. Ставь только свои и от тех, кому доверяешь.
- Токен API даёт право только ставить и снимать отметки. Его можно отозвать в боте.
- Правила уровня 1 не отправляют на сервер ни названия окон, ни файлы, ни коммиты — только итог.

## 7. Риски

- **Бот живёт на ПК.** Когда компьютер выключен, бот молчит. Принято. Если понадобится, вынесем бота на дешёвый VPS.
- **Антивирусы и PyInstaller.** Неподписанные exe иногда ловят ложные срабатывания. Помогает режим onedir и, при необходимости, подпись кода.
- **Qt весит.** Сборка будет около 40–60 МБ. Держим в рамках, исключая неиспользуемые модули Qt.
- **Лимиты Google Sheets API.** Около 60 запросов на запись в минуту. Нам нужны единицы в день, запас огромный.
- **Ключи и токены.** Хранятся в Windows Credential Manager, в базу и логи не попадают.
- **Графика персонажа.** Начинаем со своих пиксельных заглушек. Хорошие спрайты енота и домика можно заказать или нарисовать позже, код от этого не меняется.
