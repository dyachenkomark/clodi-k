# Google Таблица как база

Задачи, отметки, заметки и фокусы живут в вашей Google Таблице. Файл `clodick.db` на
компьютере — только кэш: с ним енот работает без интернета и не ждёт сеть. На новом
компьютере достаточно тех же настроек и ключа, и всё восстановится из таблицы.

Смотреть и править таблицу можно откуда угодно, в том числе с телефона через приложение
Google Таблиц. Сервер для этого не нужен.

## Обычный путь: кнопка «Sign in with Google»

При первом запуске персонаж открывает мастер настройки. На шаге с таблицей человек нажимает
«Sign in with Google», в браузере выбирает аккаунт и разрешает доступ. Клодик сам создаёт
у него в Диске таблицу `cloDICK` и начинает с ней работать. Больше ничего делать не нужно.

Права — `drive.file`: клодик видит только файлы, которые создал сам. Остальной Диск ему
недоступен. На новом компьютере после входа клодик находит свою таблицу и забирает данные.
Мастер открывается снова из меню: Setup….

Кнопка появляется, только если в сборке есть файл OAuth-клиента приложения. Его один раз
делает разработчик, см. раздел ниже. Без него мастер предлагает путь с сервисным аккаунтом.

## Для разработчика: OAuth-клиент приложения, один раз

Ссылки открывают раздел в проекте, выбранном вверху консоли Google Cloud. Проверьте, что там
нужный проект.

1. **Включите API**, в каждой ссылке кнопка Enable:
   [Google Sheets API](https://console.cloud.google.com/apis/library/sheets.googleapis.com) и
   [Google Drive API](https://console.cloud.google.com/apis/library/drive.googleapis.com).
   Drive нужен, чтобы создать таблицу и найти её на другом компьютере.
2. **Экран согласия:** [Branding](https://console.developers.google.com/auth/branding) —
   имя cloDICK и почта поддержки. Если раздел ещё не настроен, консоль сама проведёт по шагам,
   на шаге Audience выберите External.
3. **Права:** [Data Access](https://console.developers.google.com/auth/scopes) →
   Add or remove scopes → в поле ручного ввода вставьте
   `https://www.googleapis.com/auth/drive.file` → Update → Save.
4. **Кто может входить:** [Audience](https://console.developers.google.com/auth/audience).
   Пока статус Testing, входят только тестовые пользователи: Add users → своя почта Gmail.
   Для всех — Publish app. По [документации Google](https://support.google.com/cloud/answer/13463073)
   приложению только с несекретными областями, а `drive.file` к ним относится, проверка
   не обязательна. Как это выглядит на практике, я не проверял.
5. **Клиент:** [Clients](https://console.developers.google.com/auth/clients) → Create client →
   Application type: **Desktop app** → Create. В появившемся окне сразу нажмите
   **Download JSON**: секрет клиента потом может быть уже не посмотреть.
6. **Положите файл** как `google-oauth-client.json`:
   - в `%LOCALAPPDATA%\cloDICK\` — чтобы работало на этом компьютере;
   - в `src/clodick/assets/` — чтобы файл попал в сборку для других людей.
   В репозиторий он не попадёт, он в `.gitignore`.
7. **Перезапустите клодика** и откройте меню → Setup… → Next. Появится «Sign in with Google».

Если клиент уже есть, но типа Web application, создайте рядом новый типа Desktop app:
вход из программы на компьютере работает через него.

Токен входа пользователя хранится в папке данных в `google-token.json`.

## Для продвинутых: сервисный аккаунт, минут десять

Клодик ходит в таблицу от имени сервисного аккаунта Google. Это технический «пользователь»
с почтой, которому вы открываете доступ к одной таблице. Вашего пароля он не знает и других
файлов не видит.

1. **Создайте таблицу.** Откройте [sheets.new](https://sheets.new), назовите, например, `cloDICK`.
   Листы и заголовки клодик создаст сам.
2. **Создайте проект в Google Cloud.** Откройте
   [console.cloud.google.com](https://console.cloud.google.com/projectcreate), имя любое.
3. **Включите Google Sheets API.** В этом проекте откройте
   [страницу API](https://console.cloud.google.com/apis/library/sheets.googleapis.com)
   и нажмите Enable. Другие API не нужны.
4. **Создайте сервисный аккаунт.** IAM & Admin → Service Accounts → Create service account.
   Имя любое, роли не нужны, просто Done.
5. **Скачайте ключ.** Откройте созданный аккаунт → Keys → Add key → Create new key → JSON.
   Скачается файл. Переименуйте его в `google-key.json` и положите в папку данных клодика:
   `%LOCALAPPDATA%\cloDICK\` на Windows, `~/.local/share/clodick/` на других ОС.
6. **Откройте таблицу этому аккаунту.** В таблице нажмите «Настройки доступа» и добавьте
   почту сервисного аккаунта как редактора. Почта выглядит как
   `имя@проект.iam.gserviceaccount.com`, она же записана в ключе в поле `client_email`.
7. **Подключите.** Проще всего в мастере: Setup… → «I have a service account key», выберите
   файл ключа и вставьте ссылку на таблицу. Или по-старому, в `config.toml` в той же папке:

   ```toml
   [sheets]
   spreadsheet_id = "https://docs.google.com/spreadsheets/d/…/edit"   # адрес таблицы целиком
   ```

8. **Проверьте.**

   ```
   uv run clodick sync
   ```

   В ответ должно прийти `Synced as …: N rows in, M rows out.` Если что-то не так, команда
   скажет, что именно: нет файла ключа, таблица не найдена или ей не открыт доступ.
9. **Перезапустите енота.** Дальше он сверяется с таблицей раз в минуту и через пару секунд
   после каждой вашей правки. Состояние видно в подсказке значка в трее, в меню есть
   «Sync with the sheet now».

Файл `google-key.json` — секрет: не кладите его в репозиторий и никому не отправляйте.
Если он утёк, удалите ключ в Google Cloud и создайте новый.

## Листы

| Лист | Что в нём | Колонки |
|---|---|---|
| `Tasks` | Задачи | `id, project, title, due, time, repeat, status, note, done_at, created` |
| `Log` | Отметки «сделано» по дням | `id, day, item, title, done_at, source` |
| `Notes` | Заметки и результаты | `id, day, item, title, text, created, source` |
| `Focus` | Фокусы Pomodoro | `id, day, item, started, minutes` |

Всё хранится текстом: даты `2026-10-02`, моменты `2026-10-02 15:00:00`.

## Что можно делать руками

- **Добавить задачу.** Допишите строку в `Tasks`: достаточно `title`. Колонку `id` оставьте
  пустой, клодик заполнит её сам. В `due` можно писать свободно: `пт`, `завтра`, `02.10`,
  `2 октября`. Клодик приведёт дату к виду `2026-10-02`.
- **Закрыть задачу.** В `status` напишите `done`, `готово`, `да` или `x`.
- **Сделать ежедневной.** В `repeat` напишите `daily` или `каждый день`.
- **Отметить привычку.** Допишите в `Log` строку с `day` и `item`, например `сегодня` и `sport`.
- **Править и удалять** любые строки, сортировать, добавлять свои колонки, менять их порядок.
  Клодик ищет строки по `id`, а свои колонки находит по названию.

Не стоит переименовывать колонки клодика и листы: он создаст их заново.

## Как разрешаются расхождения

Клодик помнит, какой была каждая строка при прошлой сверке, и по этому видит, кто что менял.

- Поменяли только в клодике — уходит в таблицу. Поменяли только в таблице — приходит в клодик.
- Поменяли разные поля одной строки с двух сторон — берутся обе правки. Например, на телефоне
  переименовали задачу, а на компьютере без сети закрыли её.
- Поменяли одно и то же поле — побеждает таблица.
- Удалили строку в таблице — она удаляется и в клодике.
- Без интернета всё копится в кэше и уходит при следующей сверке.

## Ограничения

- У Google есть лимит запросов в минуту. По его документации это 60 чтений на пользователя,
  сам я лимит не замерял. Сверка раз в минуту — это 4 чтения, запас большой.
- Напоминает енот на компьютере. Чтобы напоминания приходили на телефон при выключенном
  компьютере, позже добавим маленький скрипт внутри самой таблицы, который шлёт их в Telegram.
- Названия рабочих задач лежат у Google. Формулируйте их без данных заказчиков.
