# Как сделать своего персонажа

Персонаж — это папка с файлом `character.toml`. Код трогать не нужно.

- **Встроенные** лежат в `src/clodick/assets/characters/`. Первый — енот, `raccoon`.
- **Свои** кладите в папку данных: `%LOCALAPPDATA%\cloDICK\characters\<имя>\` на Windows.
- **Выбрать** персонажа можно в меню «Персонаж» по правому клику или в `config.toml`: `[desktop] character = "имя"`.

Если пакет собран с ошибкой, приложение его пропустит и напишет причину в лог:
какой кадр, какая строка и что не так.

## Что обязательно

| Анимация | Когда показывается | Совет |
|---|---|---|
| `sit` | Сидит на месте | Второй кадр показывается на мгновение — удобно для моргания |
| `sleep` | Спит | Два кадра, например с буквой «Z» и без |
| `wave` | Машет, когда напоминает | Лапа вверх и вниз |
| `walk` | Гуляет | Рисуйте персонажа идущим вправо, влево кадры отражаются сами |

Необязательные анимации. Если их нет, персонаж просто обходится без этих поз.

| Анимация | Когда показывается | Совет |
|---|---|---|
| `wash` | Иногда сам возится, пока сидит | Два кадра, быстро чередуются |
| `stretch` | Иногда зевает и потягивается | Кадры идут медленно |
| `eat` | Отметили задачу в чек-листе | Жуёт угощение пару секунд |
| `look` | Курсор рядом | Два кадра: первый смотрит влево, второй вправо |
| `walk_down` | Идёт вниз по экрану, к зрителю | Вид спереди. Нет — берётся `walk` |
| `walk_up` | Идёт вверх по экрану, от зрителя | Вид со спины. Нет — берётся `walk` |

Пузо для надписи с RAM, тоже необязательно: `belly = [x, y, ширина, высота]` в пикселях арта.
Надпись видна в позах `sit`, `sleep` и `wave`, так что пузо в них должно быть на одном месте.
У енота `belly = [6, 11, 8, 4]`.

Все кадры одного размера. Размер — любой до 128×128 пикселей арта.
Экран для персонажа — пол, на который смотрят сверху под углом. Нижние строки кадра — лапы:
под ними приложение само рисует тень, а в прыжке персонаж отрывается от неё.
Енот 22×18, но персонажу можно быть и больше.

## Способ 1: текстовые кадры

Каждый символ — пиксель. Цвета символов задаются в `[palette]`, точка — прозрачность.

```toml
id = "blob"             # латиница, цифры, _ и -
name = "Капля"
author = "Маша"
description = "Оранжевая капля, прыгает от радости."
size = [6, 5]           # ширина и высота кадра

[palette]
K = "#141413"           # контур
O = "#d97757"           # тело
W = "#faf9f5"           # глаза

# Необязательно: другие цвета под тему оформления.
[variants.claude_night]
O = "#b85c3e"

[animations.sit]
frames = [
'''
.KKKK.
KOOOOK
KOWOWK
KOOOOK
.KKKK.
''',
'''
.KKKK.
KOOOOK
KOKOKK
KOOOOK
.KKKK.
''',
]

[animations.sleep]
frames = ['''
......
.KKKK.
KOKOKK
KOOOOK
.KKKK.
''']

# wave и walk — так же.
```

Готовый большой пример — `src/clodick/assets/characters/raccoon/character.toml`.

## Способ 2: PNG-листы

Удобно, если рисуете в Aseprite, Piskel или любом пиксельном редакторе.
Кадры одной анимации лежат в одной картинке в ряд, слева направо, без отступов.

```toml
id = "fox"
name = "Лис"
size = [24, 20]

[animations.sit]
sheet = "sit.png"       # файл рядом с character.toml
count = 2               # сколько кадров в ряд: картинка 48×20

[animations.sleep]
sheet = "sleep.png"
count = 2

[animations.wave]
sheet = "wave.png"
count = 2

[animations.walk]
sheet = "walk.png"
count = 4
```

Рисуйте в масштабе 1:1: один пиксель картинки — один пиксель арта.
Приложение само увеличит его в `scale` раз без размытия.
Цвета из PNG используются как есть, варианты под тему для них не работают.

## Проверить без запуска приложения

```
uv run python -c "from pathlib import Path; from clodick.characters import load_character; c = load_character(Path('путь/к/папке')); print(c.name, c.width, c.height, sorted(c.animations))"
```
