# cloDICK для Claude Code (MCP)

Claude Code видит твои задачи и темы, заводит новые, записывает результаты. Закрывает задачу только когда ты подтвердил: так записано в описании сервера для Claude.

## Подключить один раз

```bash
claude mcp add --scope user clodick -- "C:\Users\User\Desktop\my_work\diff\clodi-k\.venv\Scripts\python.exe" -m clodick.mcp_server
```

`--scope user` — сервер доступен в любой папке: в Maga, Turkov и остальных. Путь к `python.exe` — из папки проекта cloDICK на этом компьютере. Проверить: `claude mcp list` или `/mcp` внутри сессии.

Сервер запускается сам, когда Claude Code открывает сессию, и работает с той же базой, что и енот. Енот раз в несколько секунд замечает правку, обновляет чек-лист, говорит, что поменялось, и отправляет правку в Google Таблицу.

## Что умеет

| Инструмент | Что делает |
|---|---|
| `today` | чек-лист на сегодня и ближайшие 7 дней: ключи, темы, сроки, заметки |
| `list_tasks` | все открытые задачи, можно по теме |
| `list_topics` | темы и их короткие имена |
| `add_task` | задача, понимает «мага: отчёт до пт 15:00» |
| `add_note` | результат или комментарий к пункту |
| `complete` | отметить сделанным, с заметкой — только после твоего «да» |
| `reopen` | снять отметку |
| `move_task` | перенести задачу в другую тему |
| `add_topic` | новая тема |

Пункт можно назвать ключом (`task:ab12cd34`, `sport`) или частью названия.

## Как пользоваться

Просто говори Claude в обычной работе: «что у меня по Маге?», «запиши в задачу про отчёт, что черновик отправлен», «отчёт готов, закрой». Лог сервера — `%LOCALAPPDATA%\cloDICK\logs\mcp.log`.
