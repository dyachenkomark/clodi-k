# cloDICK

Лёгкий десктоп-компаньон для Windows с управлением через Telegram.
Пиксельный персонаж живёт на рабочем столе и каждый день напоминает про спорт, учёбу, язык и ваши задачи. Интерфейс на английском. Первый персонаж — добрый енот, нарисованный как будто сверху под углом; прежний енот анфас остался в меню «Персонаж» как Raccoon (classic). Второй персонаж — мышка Mouse: огромные розовые уши, глаза-пуговицы, тонкий хвост и все позы енота. Третий — пингвин Penguin: не ходит, а катается на пузе. Своих можно добавлять: [docs/CHARACTERS.md](docs/CHARACTERS.md).

## Что умеет сейчас

- Экран для енота — пол, как для Desktop Goose: он гуляет во все стороны, у него есть тень, а в прыжке он от неё отрывается. Далеко от своего места не уходит, радиус задаётся настройкой `roam`. Моргает, иногда засыпает или уходит погулять. Сменить его можно в меню «Персонаж». Енота можно перетащить мышью, место запоминается.
- Двойной клик пугает енота: он убегает и потом возвращается. Несколько раз в час он сам уходит к правому краю экрана и лезет по нему вверх, как по дереву, висит, оглядывается и слезает. Посмотреть сразу: пункт Climb the edge в меню трея.
- Клик по еноту открывает чек-лист дня. Галочка — задача сделана.
- Заметки к пунктам: кнопка ✎ у пункта открывает поле, Enter сохраняет. После галочки поле открывается само: например, «5 км за 28 минут». На пункт в день можно оставить несколько заметок, они видны под ним, крестик удаляет.
- Задачи с проектом и сроком. В строке внизу чек-листа пишете «мага: отчёт до пт 15:00», и клодик сам выделяет проект, срок и время. Понимает «завтра», «пт», «02.10», «5 октября», «через 3 дня». Просроченные и сегодняшние задачи стоят в списке дня, ближайшие семь дней — в разделе SOON. Енот напоминает о них в обычных напоминаниях, накануне срока и в назначенное время.
- Темы задач: вкладки вверху чек-листа, например Turkov, Maga, Personal, Daily. «+» заводит тему, правый клик по ней — переименовать, перекрасить, сделать ежедневной, удалить (задачи остаются). Задача, добавленная во вкладке, попадает в эту тему, в ежедневной — повторяется каждый день. Правый клик по задаче переносит её в другую тему. Темы хранятся в таблице на листе Topics.
- Google Таблица как база: задачи, отметки и заметки лежат в вашей таблице, их можно смотреть и править с телефона. Файл на компьютере — только кэш. Подключение: [docs/SHEETS.md](docs/SHEETS.md).
- Свои задачи добавляются строкой внизу чек-листа. Без галочки daily задача разовая: после отметки она видна до конца дня, потом исчезает. С галочкой повторяется каждый день. Крестик удаляет свою задачу.
- Pomodoro: кнопка ▶ у задачи в чек-листе или пункт меню Start focus. Во время фокуса енот сидит тихо, не гуляет и не напоминает, а на пузе показывает оставшиеся минуты. После фокуса задача засчитывается, начинается перерыв: 5 минут, каждый четвёртый 15. Длительности — в разделе `[pomodoro]` настроек. Сессия переживает перезапуск.
- Напоминания по расписанию: енот машет лапой и говорит, что осталось.
- Загрузка оперативной памяти написана у енота на пузе. Ещё она есть в чек-листе и в подсказке значка в трее.
- Енот не просто сидит. У него больше двадцати занятий: трёт лапки, чешет ухо, валяется на спине, танцует, играет в ку-ку, чихает, копает, нюхает пол, играет с мячиком, читает, пьёт какао, клюёт носом, поёт, показывает мускулы, виляет хвостом, роется в мусорке, икает, гоняется за хвостом и носится зигзагом. Если курсор долго стоит рядом, енот подходит посмотреть. За спорт он показывает мускулы, за учёбу читает, за язык поёт, за остальное хлопает, танцует или ест печеньку. Иногда говорит: шутки, факты про енотов, фразы по времени суток и прогрессу дня. Во время фокуса Pomodoro он тих и выбирает спокойные занятия, в перерыв игривее. Болтовня выключается пунктом Chatty в меню. Если подержать курсор на нём, покажет сердечко. Ночью чаще спит. Уворачивание и сердечко выключаются в меню пунктом Playful.
- Потерялся енот, например ушёл на выключенный монитор: пункт Bring raccoon here в меню трея зовёт его в угол экрана, где сейчас курсор.
- Меню по правому клику и в трее: чек-лист, показать или спрятать енота, прогулки, напоминания, выход.

## Первый запуск

Персонаж здоровается и открывает мастер настройки: можно выбрать, кем ему быть, подключить Google Таблицу кнопкой «Sign in with Google» и дать модель для анализа по OpenAI-совместимому API (vLLM, Ollama, LM Studio, облако). С моделью енот по утрам сам составляет план на день по задачам и заметкам, а по пункту меню Plan my day — когда попросите. Ключ API хранится в защищённом хранилище системы. Мастер снова открывается из меню: Setup….

## Запуск

Нужны [uv](https://docs.astral.sh/uv/) и Git.

```
git clone https://github.com/dyachenkomark/clodi-k.git
cd clodi-k
git checkout claude/jolly-bell-t6afa7
uv sync
uv run clodick-gui        # енот без консольного окна
```

Обновить до свежей версии и перезапустить енота: `restart.cmd` в папке проекта, двойным кликом или из терминала.

Консольные команды:

```
uv run clodick note sport "5 км за 28 минут"   # заметка к пункту
uv run clodick notes --days 7                  # заметки за неделю
uv run clodick export history.csv              # история для таблицы (или .json для LLM)
uv run clodick add "мага: отчёт до пт 15:00"   # задача с проектом, сроком и временем
uv run clodick tasks                           # открытые задачи по срокам
uv run clodick sync                            # сверить с Google Таблицей сейчас
uv run clodick status
uv run clodick done sport
uv run clodick undo sport
```

## Оформление

Четыре темы, выбираются в `config.toml`: `[desktop] theme = "..."`. По умолчанию `claude` — «Терракота».

![Темы оформления](docs/themes.png)

| Тема | Как выглядит |
|---|---|
| `classic` | Серый енот, тёмный чек-лист. |
| `claude` | Кремовая бумага, терракотовые акценты, заголовки с засечками. |
| `claude_orange` | Рыжий енот в терракоте, строгий чек-лист. |
| `claude_night` | Тёмная тема с терракотовыми акцентами. |

Пересобрать картинку с темами: `uv run python tools/theme_gallery.py docs/themes.png`.

## Где хранятся данные

Главная копия данных — Google Таблица, если она подключена: листы `Tasks`, `Log`, `Notes`, `Focus`. Как подключить и что можно править руками — в [docs/SHEETS.md](docs/SHEETS.md). Локальный SQLite `%LOCALAPPDATA%\cloDICK\clodick.db` — кэш для работы без сети: отметки (`completions`), задачи (`tasks`), заметки (`notes`), фокусы Pomodoro (`focus_sessions`). Без таблицы клодик работает только с ним. У заметки сохраняется название пункта на момент записи, так что история не ломается, если задачу удалить.

Для таблицы и LLM есть выгрузка `clodick export`. CSV: строка на каждый пункт каждого дня и на каждую заметку, колонки `day, item_key, item_title, done, done_at, note, note_at`. JSON: дни, в них пункты с отметкой и заметками и сумма фокусов. По умолчанию берётся вся история, границы задаются `--from 2026-09-01 --to 2026-09-30`.

## Настройки

Данные лежат в `%LOCALAPPDATA%\cloDICK` на Windows и в `~/.local/share/clodick` на других ОС.
Там же `config.toml`: направления, время напоминаний, начало дня, размер енота, прогулки, тема.
Изменения применяются после перезапуска.

## Разработка

```
uv run pytest           # тесты, окно проверяется без экрана
uv run ruff check       # линтер
uv run ruff format      # форматирование
uv run python tools/screenshot.py scene.png   # скриншот сцены без рабочего стола
```

Домик — текстовая карта пикселей в `src/clodick/desktop/art.py`. Персонажи — пакеты в `src/clodick/assets/characters`, формат описан в `docs/CHARACTERS.md`.
Чтобы не трогать настоящие данные при разработке, задайте другой путь:

```
set CLODICK_HOME=.clodick-dev        # Windows cmd
export CLODICK_HOME=.clodick-dev     # bash
```
